Complete End-to-End ML/DL/GenAI/LLM/RAG/LangGraph/FastAPI Course
===============================================================

This folder contains a step-by-step, beginner-to-advanced course covering:
- Machine Learning (ML)
- Deep Learning (DL)
- Generative AI (GenAI)
- Retrieval-Augmented Generation (RAG)
- Large Language Models (LLMs)
- LangGraph (agent + memory patterns)
- FastAPI end-to-end examples

Start here: each subfolder contains a clear explanation, step-by-step guides,
and runnable example scripts. All explanations use simple English.

Structure:
- ML/ - theory + implementations
- DL/ - theory + implementations (PyTorch examples)
- GenAI/ - generative models, image & text
- RAG/ - embeddings, vector stores, FAISS example
- LLM/ - fine-tuning, prompting, evaluation
- LANGRAPH/ - agent designs and memory
- FastAPI/ - example APIs integrating models and RAG

Requirements: see `requirements.txt` in this folder.

Next steps:

2. Run examples using the commands shown in each folder.
3. Ask me to expand any chapter into more depth or add notebooks.
