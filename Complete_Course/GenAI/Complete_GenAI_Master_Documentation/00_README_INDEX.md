# Complete GenAI, LangChain, LangGraph, RAG, MCP, and Ollama Study Pack

This folder is a beginner-to-advanced interview preparation pack built from the syllabus you pasted. It covers the listed CampusX-style topics and adds missing concepts that usually appear in interviews and real projects.

## How to Study This Pack

If your interview is tomorrow, do this:

1. Read `01_BIG_PICTURE_BEGINNER_NOTES.md` first. It explains the whole subject in plain English.
2. Read `02_LANGCHAIN_COMPLETE_NOTES.md` for LangChain basics, components, and code flow.
3. Read `03_RAG_COMPLETE_GUIDE.md` because RAG is one of the most common GenAI interview topics.
4. Read `04_LANGGRAPH_AGENTS_MEMORY.md` for Agentic AI, workflows, persistence, HITL, streaming, and memory.
5. Read `05_MCP_COMPLETE_GUIDE.md` for Model Context Protocol.
6. Read `06_OLLAMA_LOCAL_LLMS.md` if they ask about local models.
7. Use `07_CODE_COOKBOOK.md` as your code reference.
8. Revise `08_INTERVIEW_QA_CHEATSHEET.md` before the interview.
9. Read `09_ADVANCED_PRODUCTION_AND_BEYOND.md` for production and advanced interview coverage.
10. Use `COMPLETE_STUDY_PACK.txt` when you want one plain text file.

## Files

- `01_BIG_PICTURE_BEGINNER_NOTES.md`: complete beginner explanation of GenAI, LLMs, agents, RAG, tools, memory, and deployment.
- `02_LANGCHAIN_COMPLETE_NOTES.md`: LangChain components from models to agents.
- `03_RAG_COMPLETE_GUIDE.md`: RAG from basics to advanced RAG, CRAG, Self-RAG, hybrid search, evaluation, and production issues.
- `04_LANGGRAPH_AGENTS_MEMORY.md`: LangGraph workflows, state, nodes, edges, conditional flow, persistence, time travel, memory, subgraphs, tools, HITL, streaming.
- `05_MCP_COMPLETE_GUIDE.md`: MCP architecture, lifecycle, clients, servers, tools, resources, prompts, transports, security, and examples.
- `06_OLLAMA_LOCAL_LLMS.md`: Ollama local LLM guide, CLI, API, embeddings, model selection, local RAG.
- `07_CODE_COOKBOOK.md`: all important code snippets in one file.
- `08_INTERVIEW_QA_CHEATSHEET.md`: interview answers, comparisons, mistakes, and final revision.
- `09_ADVANCED_PRODUCTION_AND_BEYOND.md`: advanced topics, production system design, evaluation, security, fine-tuning, and deployment.
- `COMPLETE_STUDY_PACK.txt`: plain text combined notes.

## One-Line Mental Map

LLM is the brain, prompt is the instruction, LangChain connects components, RAG adds external knowledge, tools let the model act, agents decide steps, LangGraph controls reliable multi-step agent workflows, memory stores context, MCP standardizes tool/data connection, Ollama runs models locally, and evaluation tells whether the system is actually good.
