============================================================ SECTION 1 —
WHAT IS AI, ML, DL, GENAI?
============================================================

Artificial Intelligence (AI)

AI means making machines behave intelligently.

Examples: - ChatGPT - Self-driving cars - Alexa - Recommendation systems

Machine Learning (ML)

Machine Learning is a subset of AI.

Instead of hardcoding rules: - Machine learns patterns from data.

Examples: - Spam detection - House price prediction - Fraud detection

Deep Learning (DL)

Deep Learning uses Neural Networks.

Key ideas: - Input Layer - Hidden Layers - Output Layer - Weights -
Bias - Activation Functions

Popular architectures: - CNN - RNN - Transformers

Generative AI

Generative AI creates NEW content.

Examples: - ChatGPT -> text - Midjourney -> images - GitHub Copilot ->
code

============================================================ SECTION 2 —
HOW LLMs WORK
============================================================

LLM = Large Language Model

Examples: - GPT - Claude - Gemini - Llama

Core Idea:

LLM predicts NEXT WORD.

Example: Input: “I love eating”

Possible next words: - pizza - dosa - biryani

Training Process:

1.  Collect huge text data
2.  Tokenize text
3.  Train transformer model
4.  Learn patterns

Important Terms:

Token: Small text chunk.

Context Window: How much text model remembers.

Temperature: Controls randomness.

Embedding: Vector representation of text.

Fine-tuning: Training model on specific data.

Inference: Using trained model.

============================================================ SECTION 3 —
TRANSFORMERS
============================================================

Transformer is the architecture behind modern LLMs.

Key Concepts:

1.  Self Attention
2.  Multi-head Attention
3.  Positional Encoding
4.  Feed Forward Networks

Self Attention:

Model decides which words are important.

Example: “The cat sat on the mat because it was tired.”

“It” refers to cat.

Attention helps model understand this.

Formula: Attention(Q,K,V)

============================================================ SECTION 4 —
EMBEDDINGS ============================================================

Embeddings convert text into vectors.

Example: “dog” -> [0.23, 0.81, …]

Similar words have similar vectors.

Uses: - Semantic Search - RAG - Recommendation Systems

Popular Embedding Models: - OpenAI Embeddings - BGE - Instructor -
Sentence Transformers

============================================================ SECTION 5 —
VECTOR DATABASES
============================================================

Why Vector DB?

Normal DB cannot efficiently search vectors.

Vector DB stores embeddings.

Popular Vector Databases:

-   FAISS
-   ChromaDB
-   Pinecone
-   Weaviate
-   Milvus

Workflow:

1.  Convert document to chunks
2.  Create embeddings
3.  Store vectors
4.  Search similar vectors

============================================================ SECTION 6 —
RAG (RETRIEVAL AUGMENTED GENERATION)
============================================================

Definition:

RAG allows LLM to answer using external knowledge.

Problem without RAG:

LLM hallucinates.

RAG Pipeline:

1.  User Question
2.  Convert query to embedding
3.  Search vector DB
4.  Retrieve relevant chunks
5.  Send chunks + question to LLM
6.  Generate answer

Architecture:

User -> Retriever -> Vector DB -> LLM

Advantages:

-   Updated knowledge
-   Reduced hallucination
-   Private data support

============================================================ SECTION 7 —
ADVANCED RAG
============================================================

1. CRAG (Corrective RAG)

Checks if retrieved documents are useful.

If bad retrieval: - Re-search - Improve context

2. Self-RAG

Model evaluates itself.

It asks: - Is answer correct? - Do I need retrieval again?

3. Graph RAG

Uses graph relationships.

4. Hybrid Search

Combines: - Vector search - Keyword search

============================================================ SECTION 18
— COMPLETE RAG PROJECT
============================================================

Step-by-step:

1.  Load PDF
2.  Split text
3.  Create embeddings
4.  Store in vector DB
5.  Retrieve chunks
6.  Generate answer

Full Code:

from langchain_openai import ChatOpenAI from langchain_openai import
OpenAIEmbeddings from langchain_community.document_loaders import
PyPDFLoader from langchain.text_splitter import
RecursiveCharacterTextSplitter from langchain.vectorstores import Chroma
from langchain.chains import RetrievalQA

loader = PyPDFLoader(“notes.pdf”) docs = loader.load()

splitter = RecursiveCharacterTextSplitter( chunk_size=500,
chunk_overlap=50 )

chunks = splitter.split_documents(docs)

embeddings = OpenAIEmbeddings()

db = Chroma.from_documents( chunks, embeddings )

retriever = db.as_retriever()

llm = ChatOpenAI()

qa = RetrievalQA.from_chain_type( llm=llm, retriever=retriever )

response = qa.invoke(“Explain transformers”)

print(response)

============================================================ SECTION 22
— SIMPLE LANGGRAPH
============================================================

Code:

from langgraph.graph import StateGraph from typing import TypedDict

class State(TypedDict): message: str

def chatbot(state): return {“message”: “Hello”}

graph = StateGraph(State)

graph.add_node(“chatbot”, chatbot)

graph.set_entry_point(“chatbot”)

app = graph.compile()

print(app.invoke({“message”:“hi”}))
